# sns-role-summary.md

## 各SNSの役割

| SNS | 役割 | 主なコンテンツ | 投稿頻度 |
|-----|------|--------------|---------|
| TikTok | 新規視聴者獲得・認知拡大 | 60秒以内の短尺・フック重視 | 週3〜4本 |
| Instagram | 世界観の展示室・資料庫 | Reels＋カルーセル（証拠資料風） | 週2〜3本 |
| YouTube | 本編・収益化の中心 | 10〜20分の本編＋Shorts | 週1本（本編） |
| X | 噂・断片・考察誘導 | 予告・考察煽り・コメント引用 | 週3〜5本 |
| Threads | 会話・軽い世界観投稿 | 短文・調査メモ・問いかけ | 週2〜3本 |
| Substack | 読者のファン化・詳細記事 | 無料記事＋有料の完全版 | 月2〜4本 |

## SNS同士の導線

```
TikTok / Instagram（認知）
    ↓ 「続きはYouTubeで」
YouTube（深掘り・収益）
    ↓ 「考察はXで」
X / Threads（コミュニティ）
    ↓ 「完全版はSubstackで」
Substack（マネタイズ・ファン化）
```

## 1つの怪異ファイルからの展開イメージ

| 展開 | プラットフォーム | 内容 |
|-----|----------------|------|
| 予告 | X / Threads | 「次の記録を公開します」1文 |
| 短尺 | TikTok / Reel | 怪異の核心部分60秒 |
| 資料 | Instagram | 証拠写真・記録書類のカルーセル |
| 本編 | YouTube | 全体像・考察・未解決の問い |
| 考察誘導 | X | 「○分○秒に何か映っていますか？」 |
| 完全版 | Substack | 未公開の裏設定・制作メモ |
