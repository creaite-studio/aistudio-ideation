# visual-identity.md

## ロゴの方向性

- モノクロベース（黒・白・グレー）
- 「記録」「報告書」「ファイル」を想起させるデザイン
- 過度に怖くしない。淡々とした公式文書感

## アイコンの方向性

- 正方形クロップで映える構図
- 封筒・ファイルフォルダ・監視カメラなどのモチーフ候補
- 顔出しなし

## ヘッダー画像の方向性

- 静止した映像のスクリーンショット風
- 「KF001」などの記録番号・タイムスタンプを重ねる
- ノイズ・グレイン感を加える

## 投稿デザインの雰囲気

- 監視カメラ映像風（タイムスタンプ・REC表示）
- 古い報告書・官公庁文書風（スタンプ・消印・手書きメモ）
- ターミナル・ログファイル風（等幅フォント・緑テキスト）

## フォント方針

- 日本語: 游ゴシック / Noto Sans JP（機械的な印象）
- 英数字: Courier New / Source Code Pro（記録・コード感）
- 手書き風は「証拠書類」演出時のみ使用

## 余白・ノイズ・質感

- グレイン（ざらつき）を適度に加える
- ビネット（周辺減光）で古い映像感を出す
- 余白は多め。詰め込まない

## 使用する画像のトーン

- 彩度低め（モノクロ〜セピア〜くすんだカラー）
- AI生成素材を積極的に使用
- 「普通の場所」「日常のシーン」をベースにする（非日常を際立てるため）
