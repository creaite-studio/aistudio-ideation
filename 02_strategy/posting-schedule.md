# posting-schedule.md

## 週次投稿スケジュール

| 曜日 | プラットフォーム | コンテンツ | 目的 |
|------|----------------|-----------|------|
| 月 | TikTok / Reel | 短尺（60秒）考察煽り | 認知拡大 |
| 水 | TikTok / Reel | 短尺（60秒）シリーズ予告 | フォロワー誘導 |
| 木 | X / Threads | 断片投稿・調査メモ | コミュニティ形成 |
| 金 | YouTube | 本編（10〜20分） | 収益・信頼構築 |
| 金（夜） | X | 考察煽りポスト | エンゲージメント |
| 土 | TikTok / Reel | 短尺（考察の答え合わせ or 次回予告） | リテンション |
| 土 | Instagram | カルーセル（証拠資料） | 世界観の展示 |

**週6〜7投稿（TikTok/Reel×3 + YouTube×1 + X/Threads×複数 + Instagram×1）**

## 1怪異ファイルから作る投稿数

| プラットフォーム | 投稿数 | 内容 |
|---------------|-------|------|
| TikTok | 2〜3本 | 予告・本編抜粋・考察煽り |
| Instagram | 1〜2本 | Reels＋カルーセル |
| YouTube | 1本 | 本編（＋Shorts 1〜2本） |
| X | 3〜5本 | 予告・投稿告知・考察引用 |
| Threads | 2〜3本 | 調査メモ・問いかけ |
| Substack | 1本 | 完全版記事 |

→ **1怪異ファイルで約10〜15投稿を生成できる**

## 投稿最適時間帯

| プラットフォーム | 推奨時間 |
|---------------|---------|
| TikTok | 平日 20:00〜22:00 |
| Instagram Reel | 平日 20:00〜22:00 |
| YouTube | 金・土 20:00 |
| X | 投稿日の朝8:00（予告） + 投稿後2時間（考察煽り） |

## 制作日と投稿日の分離

- 制作: 週1〜2回まとめて作る（火曜・木曜が目安）
- 投稿: Bufferでスケジュール予約
- コメント返信: 投稿後30分以内に対応（アルゴリズム的に重要）

## 月間投稿数

- TikTok/Reel: 12〜16本
- YouTube本編: 4本
- YouTube Shorts: 4〜8本
- X: 15〜20本
- Instagram: 4〜8本
- Threads: 8〜12本
- Substack: 2〜4本
