# 30-days-plan.md

## 全体目標

- TikTok / Instagram 合計フォロワー 300人
- YouTube 本編 2本投稿
- 怪異ファイル 2件（KF001・KF002）を完成・公開
- 「世界観が伝わっている」コメントを少なくとも1件獲得

---

## 1週目：アカウント基盤構築（Day 1〜7）

### 目的
「見た人が世界観を即座に理解できるアカウント」を作る

### タスク
- [ ] 全SNSアカウントを統一コンセプトで開設（TikTok / Instagram / YouTube / X / Threads / Substack）
- [ ] `01_account/profile-texts.md` を参照してプロフィール文を設定（標準版を使用）
- [ ] `01_account/visual-identity.md` を参照してアイコン・ヘッダーを制作
  - アイコン: 暗め・静止画・「記録」を感じさせるデザイン
  - ヘッダー: ファイル番号・スキャン感・証拠書類風
- [ ] Bufferアカウント登録・各SNSを連携
- [ ] Linktree（または類似）でプロフリンクを整備
  - YouTube本編 → Substack → X考察 の順で配置
- [ ] `03_platforms/` の各テンプレートを確認・把握

### 完了条件
全SNSアカウントのプロフィールを見た第三者が「怪異・記録系のアカウントだ」と理解できる状態

---

## 2週目：第1怪異ファイル（KF001）制作（Day 8〜14）

### 目的
世界観の核を作る。完璧でなくてよい、公開できるクオリティで完成させる

### タスク
- [ ] `04_kaii-files/kaii-index.md` にKF001を登録
- [ ] `KF001_[怪異名]/master.md` に怪異の核心を書く
  - 怪異の一文要約
  - フィクション/実話要素の混在度
  - 未解決の問い（視聴者に投げかける問い）
- [ ] `story.md` に原文・報告書本文を書く
- [ ] `evidence.md` に証拠・資料設定を書く（手紙・映像・ログ・写真など）
- [ ] `prompts.md` に画像生成プロンプトを書く
- [ ] RunwayまたはKlingでAI素材を生成・`assets/` に保存
- [ ] CapCutで動画編集（TikTok用 60秒）
- [ ] `production/` の各SNSファイルを作成（TikTok / Instagram / YouTube）

### 注意
- Part 1/2 の表記は使わない → `記録No.001` 形式で統一
- BGM・効果音は最小限。語り口は淡々と

---

## 3週目：投稿開始・初動計測（Day 15〜21）

### 目的
実際に投稿して、何が反応を得るかデータを取る

### タスク
- [ ] TikTok 短尺1本目を投稿（フック選定：未解決事件 or AI映像 from `03_platforms/tiktok/template.md`）
- [ ] Instagram Reel 1本目を投稿（TikTokの原ファイルを使用。TikTok保存ファイルは使わない）
- [ ] Instagram カルーセル1本目を投稿（証拠資料 or 記録ファイル形式）
- [ ] YouTube 本編1本目を投稿（KF001完全版）
- [ ] X に予告・考察煽りポストを開始（`03_platforms/x/template.md` 使用）
- [ ] Threads に断片・調査メモを投稿
- [ ] `publishing/published-log.md` に初動データを記録（48時間後の再生数・フォロワー増減）
- [ ] コメント返信を投稿後30分以内に実施（最初の1時間が最重要）

### 初動で確認すること
| 指標 | 確認タイミング |
|-----|-------------|
| TikTok再生数 | 投稿後1h / 6h / 24h |
| Instagram Reels再生数 | 投稿後24h |
| YouTube視聴完了率 | 投稿後72h |
| コメントの内容 | 投稿後24h（考察か、感想か、ネガティブか） |

### タスク

- [ ] `KF002_[怪異名]/master.md` の制作を開始（KF001の反省を活かす）
- [ ] TikTok 短尺2本目を投稿（KF001の続き or KF002の予告）

## KPI（毎週確認）

| 指標 | 目標値 | 判断基準 |
|-----|-------|---------|
| TikTok / Reel フォロワー増加/週 | +50人 | 下回る場合はフック文言を変更 |
| YouTube 視聴完了率 | 40%以上 | 下回る場合は導入部を短縮 |
| TikTok 平均再生数 | 1,000回以上/本 | 下回る場合は投稿時間帯・ハッシュタグを見直し |
| コメント数/本 | 10件以上 | 下回る場合はコメント誘導文を変更 |
| 保存率（Instagram） | 5%以上 | 下回る場合はカルーセル構成を見直し |

---

## 30日終了後の判断

`05_analytics/` のデータをもとに以下を判断する：

- **継続するジャンル**: 再生数・コメント数が高い題材を優先
- **テンプレートの修正**: `03_platforms/` を実績に合わせて更新
- **Substack有料化のタイミング**: フォロワー500人 or 無料読者100人達成で開始を検討
- **制作フローの改善**: 1怪異ファイルの制作時間を記録し、短縮できる工程を特定
