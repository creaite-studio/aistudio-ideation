## 1. プロダクト概要

### What
キャラクター・世界観・伏線をノードグラフで視覚的に管理できる、物語創作者向けWebアプリ。

### Why（作る理由）
- Nola: 執筆に強いが、グラフで世界観を見渡す機能がない
- WorldType: 設定管理に強いが、執筆との統合がない・グラフUIが弱い
- Obsidian: 汎用すぎて創作に特化していない
- **空白:** 「書く」と「見渡す」が同一画面で完結するツールが存在しない

### Who
- **Primary:** 登場人物・世界観が複雑になってきた小説家・脚本家志望（吉田蒼ペルソナ）
- **自分自身:** ホラー長編フィクションの創作管理に使う最初のユーザー

### 差別化の一言
「物語を書きながら、世界観を見渡せる」

## 2. MVPのスコープ

### MVPに含むもの ✅
| 機能カテゴリ | 機能 |
|------------|------|
| プロジェクト | 物語プロジェクトの作成・切り替え・削除 |
| キャラクター | キャラクターの追加・編集・削除（名前・説明・属性タグ） |
| 関係エッジ | キャラクター間の関係を線で繋ぐ（ラベル付き：「知っている」「敵対」「秘密を知っている」等） |
| グラフビュー | インタラクティブなノードグラフ表示（ドラッグ・ズーム・パン） |
| メモ | キャラクターや関係にメモ・伏線タグを紐付け |
| 認証 | メールアドレス + パスワードでのサインアップ / ログイン |

### MVPに含まないもの ❌（後回し）
| 機能 | 理由 |
|------|------|
| 執筆エディタ | Nolaと競合せず、管理ツールとして差別化する |
| AI生成 | MVP後の有料機能として追加 |
| エクスポート（PDF/JSON） | プレミアム機能として有料化する |
| モバイルアプリ | Web先行、反応を見て検討 |
| コラボレーション | 個人利用に絞ってシンプルに保つ |
| 場所・世界観ノード | Phase 2で追加（キャラクターで実績を作ってから） |

## 3. 機能仕様

### 3-1. プロジェクト管理

```
- ユーザーは複数の「物語プロジェクト」を作成できる
- プロジェクトには「タイトル」「ジャンル（任意）」「メモ（任意）」を設定できる
- プロジェクト一覧画面から切り替えられる
- プロジェクトの削除は確認ダイアログを挟む
```

### 3-2. キャラクター管理

```
- キャラクターに設定できる項目:
  - 名前（必須）
  - 説明（任意・400字以内）
  - 属性タグ（任意・複数可：例「主人公」「敵対者」「死亡済み」）
  - メモ（任意・伏線・補足情報の自由記述）
  - アイコンカラー（ノードの色。識別用）
- キャラクターはプロジェクト内に何人でも追加できる
- キャラクター一覧はサイドパネルに表示
```

### 3-3. 関係エッジ

```
- 2つのキャラクターを繋ぐ「関係」を作成できる
- 関係に設定できる項目:
  - ラベル（例:「親子」「幼馴染」「秘密を共有」「敵対」）
  - 方向性（双方向 / 一方向）
  - 伏線フラグ（ON/OFF：ONの場合、エッジを点線で表示）
  - メモ（任意）
- 関係はグラフ上でクリックして編集できる
```

### 3-4. グラフビュー（中核機能）

```
- ノード:
  - キャラクターを円または矩形のノードで表示
  - ノードに名前・アイコンカラーを反映
  - クリックで詳細パネルを開く
  - ドラッグで位置を自由に移動できる
  - 位置はDB保存（再ログイン後も保持）
- エッジ:
  - 関係を線で表示（通常は実線・伏線フラグはONは点線）
  - ラベルを線の中央に表示
  - クリックで関係の編集パネルを開く
- 操作:
  - ズームイン/アウト（マウスホイール）
  - 全体表示にフィット（ボタン1つ）
  - ノード追加ボタン（グラフ内から直接追加できる）
```

### 3-5. 認証

```
- メールアドレス + パスワードでサインアップ
- ログイン / ログアウト
- パスワードリセット（メール送信）
- 各ユーザーのデータは完全に分離（他ユーザーのデータは見えない）
```

## 4. 画面構成

```
/ (ランディングページ)
  └─ /signup (新規登録)
  └─ /login (ログイン)
  └─ /dashboard (プロジェクト一覧)
       └─ /project/:id (グラフビュー ※メイン画面)
            ├─ サイドパネル: キャラクター一覧・追加
            ├─ グラフ: ノード・エッジのインタラクティブ表示
            └─ 詳細パネル: 選択中のキャラクター/関係の編集
```

## 5. 技術スタック

| カテゴリ | 技術 | 選定理由 |
|---------|------|---------|
| フロントエンド | React + TypeScript | 型安全・エコシステム |
| グラフUI | React Flow | ノードグラフの実装コストを最小化。ドラッグ・ズーム込みで提供 |
| スタイリング | Tailwind CSS | 高速UI構築 |
| バックエンド/DB | Supabase | Auth + PostgreSQL + リアルタイム更新をゼロ構成で提供 |
| ホスティング | Vercel | GitにpushするだけでデプロイされるCIが無料 |
| 状態管理 | Zustand | シンプルな操作で十分。Reduxは過剰 |

**代替案（コーディングが難しい場合）:** Bubble（No-code）でグラフUIはBubble Pluginで代替可能だが、React Flowのような滑らかな操作性は難しい。

## 7. 開発ロードマップ

| Week | マイルストーン | 主なタスク |
|------|-------------|----------|
| Week 1 | 基盤構築 | Supabase設定・認証実装・プロジェクトCRUD・画面ルーティング |
| Week 2 | コア機能 | キャラクターCRUD・React Flowでグラフ表示・ノード追加/削除 |
| Week 3 | 関係機能 | エッジのCRUD・ラベル・伏線フラグ・位置の保存 |
| Week 4 | 仕上げ | UIの整備・バグ修正・Vercelデプロイ・βリリース |
