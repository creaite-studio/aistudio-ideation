## 設計思想

```
MVP      → 「見渡せる」
Phase 2  → 「世界が立体化する」
Phase 3  → 「複数話をまたいで管理できる」  ← 最大の差別化点
Phase 4  → 「AIが気づかせてくれる」        ← 有料機能の柱
Phase 5  → 「書く場所もここになる」
保留     → タイムライン管理（Phase 4.5 以降）
```

各フェーズは**自分が物語を書いていて実際にぶつかる壁**を解決する順番で積み上げる。

---

## 競合（Nola）との差別化根拠

Nolaができないことを差別化軸に据える。

| Nolaができないこと | 当ツールの解決アプローチ |
|-----------------|----------------------|
| 複数話・シリーズをまたいだ伏線管理 | Phase 3: エピソード管理 + 伏線横断トラッカー |
| グラフの動的操作（ドラッグ・ズーム） | MVP: React Flowによるインタラクティブグラフ |
| 書く前のプロット設計支援 | Phase 4: AIによるプロット方向性提案 |
| 表の関係図 vs 裏の関係図の分離 | Phase 3: 表/裏グラフの切り替え表示 |
| 矛盾チェック | Phase 4: AIによる設定矛盾の検出 |

## フェーズ別ロードマップ

---

### MVP — 「見渡せる」

**目的:** キャラクターと関係をグラフで見渡せる最小限の環境を作る

| 機能カテゴリ | 概要 |
|------------|------|
| プロジェクト管理 | 物語プロジェクトの作成・切り替え・削除 |
| キャラクター管理 | キャラクターの追加・編集・削除（名前・説明・属性タグ） |
| 関係エッジ | キャラクター間の関係を線で繋ぐ（ラベル・方向性・伏線フラグ） |
| グラフビュー | インタラクティブなノードグラフ（ドラッグ・ズーム・パン） |
| 認証 | メールアドレス + パスワードでサインアップ / ログイン |

**詳細要件:** `物語作成支援ツール-MVP.md` 参照

---

### Phase 2 — 「世界が立体化する」

**目的:** 人物だけでなく、場所・陣営もグラフに乗せて世界観を立体的に管理する

| 機能 | 概要 |
|------|------|
| 場所ノード | 舞台・地名をノードで追加。キャラクターと「住んでいる」「訪れた」でエッジ接続 |
| 組織・陣営グループ | 複数キャラを1グループに束ねる。グループ間の対立関係もエッジで表現 |
| ノード種別フィルター | 「キャラのみ」「場所のみ」などフィルター切り替えで見やすくする |

**詳細要件:** 別ドキュメントで定義予定

---

### Phase 3 — 「複数話をまたいで管理できる」★最大差別化点

**目的:** シリーズ・連作の横断管理。Nolaに存在しない機能領域。  
**背景（Q3）:** 各話が複雑に絡み合う伏線・裏設定の管理が一番の課題

| 機能 | 概要 |
|------|------|
| エピソード管理 | プロジェクト内に複数の「話/章」を作成。各話に登場キャラ・使用伏線を紐付け |
| 伏線横断トラッカー | 伏線を「仕込んだ話」→「回収する話」で管理。未回収伏線を一覧表示 |
| 表/裏グラフの切り替え | 「読者が知っている関係図」と「作者だけが知っている真実の関係図」を分離して表示 |
| 知識状態管理 | 「N話時点でキャラAが知っていること/知らないこと」をフラグで管理 |
| シーンメモ（簡易エディタ） | 各話・各シーンにテキストメモを記録（Phase 4の矛盾チェックの下地） |

**詳細要件:** 別ドキュメントで定義予定

---

### Phase 4 — 「AIが気づかせてくれる」（有料機能の柱）

**目的:** グラフ・メモのデータをAIが読み取り、人間が見落とす矛盾や可能性を示す  
**背景（Q2/Q3）:** 矛盾チェックのために執筆エディタが必要 → Phase 3のシーンメモがその下地になる

| 機能 | 概要 |
|------|------|
| 矛盾チェック | シーンメモ×知識状態を照合し「このシーンでAはBの正体を知らないはずです」と指摘 |
| 伏線サジェスト | 既存の関係・設定から「こんな伏線が生えそうです」をAIが提案 |
| プロット方向性の提案 | テーマ・ジャンル・登場キャラから「こういう物語が作れそう」を複数提示（Q3の課題①） |
| キャラクター動機分析 | 設定から「このキャラならこう行動するはず」の一貫性をAIが確認 |

**詳細要件:** 別ドキュメントで定義予定

---

### Phase 5 — 「書く場所もここになる」

**目的:** Nolaに踏み込む。設定資料を参照しながら執筆できる統合環境へ  
**背景（Q2）:** 矛盾チェック等の精度を上げるため、執筆テキストも取り込む方向

| 機能 | 概要 |
|------|------|
| 本格執筆エディタ | 縦書き・ルビ対応。設定資料をサイドパネルで参照しながら執筆 |
| エクスポート（有料） | 原稿PDF・設定資料集・グラフ画像の書き出し |
| 世界観グラフの公開 | URLで読者に公開できる読み取り専用ビュー |

**詳細要件:** 別ドキュメントで定義予定

---

Phase 3のシリーズ管理が安定してから、時系列を横軸で見る機能として追加する。  
詳細スコープは Phase 3 完了後に議論する。
