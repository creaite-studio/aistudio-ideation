## Phase 1: アイデア一覧（5件）

### #1 — 「怖い運勢」ホラー×スピリチュアルアカウント
- **ペルソナ:** 🎨 Creative Expert
- **説明:** 毎日「今日の凶兆」「呪われた日付」などホラー世界観で包んだ占いコンテンツを発信。通常の占いアカウントと完全差別化しつつ占い系アフィリに繋げる。
- **💡:** 怖い世界観の好みをそのままコンテンツ軸にできる最短経路。
- **形態:** SNS
- **タグ:** `#sns` `#スピリチュアル`

### #4 — AI自動生成ホラー短編SNSアカウント
- **ペルソナ:** 💻 Technical Expert
- **説明:** Claude/GPTでホラーショートストーリーを毎日自動生成・投稿。AIツール紹介アフィリと組み合わせて「AI情報発信×怖い話」というニッチを確立。
- **💡:** コンテンツ生成コストをほぼゼロにしながら投稿頻度を最大化できる。
- **形態:** SNS
- **タグ:** `#sns` `#app`

### #12 — 都市伝説×民俗学アーカイブアカウント
- **ペルソナ:** 🔬 Academic Researcher
- **説明:** 日本・海外の怖い話を民俗学・文化人類学の視点で解説。怖い話好きの知的好奇心を刺激する。書籍・Kindleアフィリとの相性が良い。
- **💡:** 「怖い話好き」の中でも「理由を知りたい層」は未開拓。
- **形態:** SNS / note
- **タグ:** `#sns` `#note`

### #13 — 読者参加型「怖い体験談」投稿アカウント
- **ペルソナ:** 🧑‍🤝‍🧑 Social Scientist
- **説明:** フォロワーが怖い体験を投稿できる参加型Xアカウント。UGCでバイラル拡散しやすく、スピリチュアル系アフィリへの導線を設置。
- **💡:** コンテンツ制作を読者に委ねることで副業リソースを最小化できる。
- **形態:** SNS
- **タグ:** `#sns` `#スピリチュアル`

### #17 — 「呪われた場所」ARマップアプリ
- **ペルソナ:** ⚡ Disruptor
- **説明:** 実際の位置情報に怖い伝承・都市伝説をARオーバーレイして体験できるアプリ。ゲーム×ホラー×観光の三方向に訴求。
- **💡:** Googleマップ×ホラーという前例のない組み合わせ。
- **形態:** アプリ
- **タグ:** `#app`

## Phase 4: Deep Dive — 統合コンセプト

**「物語作成支援ツール × 怖い世界観創作 × X/note発信」**

### 三層構造

```
【Layer 1: ツール開発】
  物語作成支援Webアプリ（汎用設計）
  ・キャラクター・関係性をノードグラフで管理
  ・伏線・世界観・場所をタグで紐付け
        ↕
【Layer 2: 物語創作】
  怖い世界観のフィクション（長編 or 連載）
  ・H2〜H5の要素を世界観の設定として組み込む
        ↕
【Layer 3: 発信】
  X（断片・開発ログ）+ note（連載・有料記事）
```

### Implementation Steps

| フェーズ | 期間 | アクション |
|---------|------|----------|
| 0: 発信先行 | 今すぐ | Xアカウント開設・コンセプト宣言・仮の関係図をObsidianで作って投稿 |
| 1: MVP + 世界観設計 | Month 1 | MVP3機能（ノード・エッジ・メモ）実装・物語第一章執筆 |
| 2: 公開ベータ + 連載 | Month 2 | ツールβ公開・note連載開始・有料解説記事投稿 |
| 3: マネタイズ | Month 3〜 | ツールプレミアム導入・note有料記事・H1（読者投稿）解放 |

### Risks & Mitigations

| リスク | 対応 |
|--------|------|
| ツール開発が長引く | 発信を先行。Obsidian/Miroで仮運用しながら投稿継続 |
| 物語クオリティ不安で止まる | 完成品でなく「過程」を売りにする |
| ツール需要が読めない | 発信しながら反応を見てから本格開発 |
| 発信軸がぶれる | 「創作者向けツールを作る創作者」で一貫させる |

### SNS展開ブリーフ

- **コンセプト一言:** 「怖い世界観の物語を書きながら、管理ツールも自分で作っている創作開発者」
- **ターゲット:** 20〜35歳・小説/脚本書きたい人・ホラー好き・ビルドインパブリック興味層
- **推奨プラットフォーム:** X + note
- **SNS目的:** ブランディング → ツール集客 → note販売
- **差別化の軸:** 「使う人が作った」ツール。ツールと物語が互いの広告になる自己完結エコシステム

### 🚀 First Action

Xで「物語作成ツールを作りながら怖い話を書くアカウントを始めます」と宣言し、Obsidianかホワイトボードで書いた登場人物の関係図の写真を一枚添付して投稿する。
