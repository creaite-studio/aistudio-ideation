# platform-overview.md

## 各SNSの目的と成功指標

| SNS | 目的 | 主な投稿内容 | 成功指標 |
|-----|------|------------|---------|
| TikTok | 新規認知・拡散 | 60秒以内の短尺 | 再生数・フォロワー増加率 |
| Instagram | 世界観展示・ファン化 | Reels＋カルーセル | 保存数・プロフィール訪問数 |
| YouTube | 深掘り・収益化 | 10〜20分本編＋Shorts | 視聴完了率・チャンネル登録者数 |
| X | 考察誘導・リアルタイム | 予告・断片・考察煽り | リポスト数・コメント数 |
| Threads | 会話・世界観 | 短文・調査メモ・問いかけ | 返信数・フォロワー増加 |
| Substack | ファン化・マネタイズ | 完全版記事・裏設定 | 有料読者数・開封率 |

## SNS同士の導線

```
TikTok / Instagram（認知）
    ↓ 「続きはYouTubeで」
YouTube（深掘り・収益）
    ↓ 「考察はXで」「完全版はSubstackで」
X / Threads（コミュニティ）
Substack（マネタイズ・ファン化）
```

## 1つの怪異ファイルからの展開

| タイミング | SNS | 内容 |
|-----------|-----|------|
| 公開3日前 | X / Threads | 「次の記録を公開します」予告 |
| 公開日 | TikTok | 怪異の核心60秒 |
| 公開日 | YouTube | 本編（10〜20分） |
| 公開翌日 | Instagram | 証拠書類カルーセル |
| 公開2日後 | X | 「○○に気づいた人はコメントへ」考察煽り |
| 公開1週間後 | Substack | 完全版・裏設定・制作メモ |
