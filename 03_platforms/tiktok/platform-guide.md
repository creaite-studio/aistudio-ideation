# TikTok Platform Guide

## 1. このSNSの役割
新規視聴者の獲得・認知拡大。YouTubeへの誘導起点。

## 2. 投稿する内容
- 怪異の核心部分（60秒以内に圧縮）
- 「これ本当にあったの？」という考察煽り
- 次回予告・シリーズ更新告知

## 3. 投稿しない内容
- 10分を超える長尺
- 説明が多い解説系
- 怖さより「解説」になっているもの

## 4. 投稿方針
- 最初の3秒で止まらせる（フック必須）
- オチをつけない・余白を残す
- テキストオーバーレイは最小限
- 元データから直接アップ（TikTokロゴなしで）

## 5. 推奨投稿頻度
週3〜4本（平日 20:00〜22:00）

## 6. 成功指標
- 平均再生数: 1,000回以上/本
- フォロワー増加: 週+50人
- コメント数: 10件以上/本

## 7. 制作チェックリスト
- [ ] 最初の3秒にフックがあるか
- [ ] 縦型（9:16）になっているか
- [ ] 音声あり前提の編集になっているか
- [ ] TikTokウォーターマークなしのファイルを保存したか
- [ ] 概要欄テンプレを適用したか

## 8. 投稿チェックリスト
- [ ] キャプションにフック1行が入っているか
- [ ] ハッシュタグ15〜20個を設定したか
- [ ] 「続きはYouTubeで→プロフURLから」を入れたか
- [ ] フィクション免責文を入れたか
- [ ] 投稿後30分以内にコメント返信したか

## 9. 改善時に見るポイント
- 視聴完了率が低い → フックの後に離脱している可能性。最初の10秒を見直す
- コメントがつかない → 問いかけ・考察煽りが不足。「どう思いますか？」を入れる
- フォロワー転換率が低い → シリーズ感が伝わっていない可能性。プロフィールを見直す
