# TikTok Template

## 動画構成テンプレ

### 秒数構成
- 0〜3秒：異常の提示（フック）
- 3〜10秒：状況説明
- 10〜25秒：証言・記録・証拠
- 25〜40秒：異常の核心
- 40〜50秒：未解決の結末
- 50〜60秒：コメント誘導

### 台本の型（基本）
```
この[映像/手紙/記録]は、[場所/状況]で[発見/記録]されたものです。
最初は、ただの[日常的なもの]だと思われていました。
しかし、[解析/調査]すると[異常な点]が確認されました。
問題は、[説明できない核心]です。
現在も、この[現象/事件]は説明されていません。
```

### 台本の型（詳細版）

**0〜3秒（フック）**
```
[映像/画像の中の違和感]——これが[事件名/現象名]の始まりです。
```

**3〜15秒（状況説明）**
```
[場所]で[時期]に発見されたこの[記録/手紙/映像]。
最初は[無害な説明]と思われていた。
```

**15〜35秒（異常の詳細）**
```
しかし[解析/調査]すると、[説明できない点]が確認された。
[具体的な異常の描写]。
```

**35〜50秒（核心）**
```
問題は、[最も説明できない点]だ。
[説明しようとしたが説明できない試みの描写]。
```

**50〜60秒（未解決＋コメント誘導）**
```
現在も[事件/現象]の説明はできていない。
あなたはどう思いますか？
```

## キャプションテンプレ

### 基本型
```
[フック1行：疑問形 or 衝撃的な一文]

[本文2〜3行：状況説明。事実だけ書く]

続きはYouTubeで→プロフィールのリンクから🔗

#ホラー #怖い話 #心霊 #未解決事件 #考察 #モキュメンタリー #フィクション #ヒトコワ #怪談 #都市伝説 #horror #scary #mysterytiktok #恐怖 #閲覧注意
※フィクションです
```

### フックのバリエーション
```
疑問型  ：「この映像、本当にAIが生成したものですか？」
数字型  ：「3人の関係者に届いた手紙。全員が同じ言葉を書いていた。」
共感型  ：「ホラーを作ろうとしただけなのに、なぜこうなった」
逆張り型：「これはフィクションです。でも説明できないことが1つあります。」
衝撃型  ：「この部屋で[X]人[死亡/退去]していますが、今も入居者を募集しています」
```

## 避けること

- 感情的な音楽・BGMの多用（世界観が壊れる）
- 字幕なし（無音環境・聴覚障害ユーザーへの対応も兼ねる）
- テロップ読み上げのみの動画（映像としての価値がない）
- 過激な効果音・ジャンプスケア（アルゴリズムに嫌われやすい）
- TikTok保存ファイルをInstagramに流用（ウォーターマークで到達率が下がる）
- 「Part 1 / Part 2」表記（→ `記録No.001` 形式を使用）
- 毎回ジャンルが変わる投稿（認知されにくくなる）
