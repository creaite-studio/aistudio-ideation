# TikTok Template

## 動画構成テンプレ

### 秒数構成
- 0〜3秒：異常の提示（フック）
- 3〜10秒：状況説明
- 10〜25秒：証言・記録・証拠
- 25〜40秒：異常の核心
- 40〜50秒：未解決の結末
- 50〜60秒：コメント誘導

### 台本の型
```
この[映像/手紙/記録]は、[場所/状況]で[発見/記録]されたものです。
最初は、ただの[日常的なもの]だと思われていました。
しかし、[解析/調査]すると[異常な点]が確認されました。
問題は、[説明できない核心]です。
現在も、この[現象/事件]は説明されていません。
```

## キャプションテンプレ

### 基本型
```
[フック1行：疑問形 or 衝撃的な一文]

[本文2〜3行：状況説明。事実だけ書く]

続きはYouTubeで→プロフィールのリンクから🔗

#ホラー #怖い話 #心霊 #未解決事件 #考察 #モキュメンタリー #フィクション #ヒトコワ #怪談 #都市伝説 #horror #scary #mysterytiktok #恐怖 #閲覧注意
※フィクションです
```

### フックのバリエーション
```
疑問型  ：「この映像、本当にAIが生成したものですか？」
数字型  ：「3人の関係者に届いた手紙。全員が同じ言葉を書いていた。」
共感型  ：「ホラーを作ろうとしただけなのに、なぜこうなった」
逆張り型：「これはフィクションです。でも説明できないことが1つあります。」
衝撃型  ：「この部屋で[X]人[死亡/退去]していますが、今も入居者を募集しています」
```
