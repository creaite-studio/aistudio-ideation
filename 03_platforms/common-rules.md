## シリーズ番号ルール（Part制の廃止）

### 使わない表記
- Part 1 / Part 2
- 前編 / 後編
- 第1話 / 第2話

### 使う表記
| 用途 | 形式 | 例 |
|-----|------|---|
| 怪異ファイル番号 | `KF001` | KF001, KF002, KF003... |
| 動画内シリーズ番号 | `記録No.001` | 記録No.001, 記録No.002... |
| 英語表記（海外向け） | `Case 001` | Case 001, Case 002... |
| Substack / 調査報告 | `調査報告 #001` | 調査報告 #001, 調査報告 #002... |

### 理由
「Part 1/2」は続きを見ることを強制するフォーマットで離脱率が上がる。
「記録No.」は「すでにアーカイブに存在する資料を閲覧している」という世界観に沿っている。

## コメント誘導テンプレート

投稿の最後または概要欄に必ず1つ入れる。毎回同じものを使わず、ローテーションする。

### 選択型（二択を迫る）
```
あなたはAとBどちらだと思いますか？
A：[解釈1]
B：[解釈2]

コメントで教えてください。
```

### 疑問型（具体的な謎を投げる）
```
この[映像/記録/証言]の[○○]、何に見えますか？

気づいた人はコメントしてください。
```

### 継続型（次回への引き）
```
続きが気になる人は🔖

[次の怪異 or 次回の更新予告]
```

### 考察型（知っている人だけ）
```
この[映像/記録]に仕込まれた違和感、気づいた人だけコメントしてください。
```

## 免責表記テンプレ

全プラットフォーム・全投稿に必ず記載する。

### 短縮版（TikTok / X / Threads）
```
※フィクションです
```

### 標準版（Instagram / YouTube 概要欄 / Substack）
```
※このコンテンツはフィクションです。実在の人物・事件・場所とは一切関係ありません。
```

## クロスポスト注意事項

| 投稿元 | 投稿先 | 注意点 |
|-------|-------|-------|
| TikTok | Instagram Reel | TikTok保存ファイルは使わない（ウォーターマーク）。CapCutの原ファイルを直接アップロードする |
