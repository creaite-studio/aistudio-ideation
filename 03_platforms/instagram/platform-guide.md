# Instagram Platform Guide

## 1. このSNSの役割
世界観の展示室・資料庫。ビジュアルで怪異の「証拠」を見せる場所。

## 2. 投稿する内容
- Reels（TikTokと同素材・元データから直接アップ）
- カルーセル（証拠書類・記録写真風の資料）
- Stories（Xでの考察煽りと連動）

## 3. 投稿しない内容
- TikTokのウォーターマーク付き動画（リーチが落ちる）
- テキストのみの投稿
- 世界観と無関係なオフショット

## 4. 投稿方針
- アプリ内楽曲を使う（外部音源はリーチ減）
- Reelsは15〜30秒が最適
- カルーセルは8枚以内で完結させる
- プロフィールのリンクに Linktree を設置する

## 5. 推奨投稿頻度
週2〜3本（Reels + カルーセル）

## 6. 成功指標
- 保存数: 1投稿あたり20件以上
- プロフィール訪問数: 再生数の10%以上
- フォロワー増加: 週+30人

## 7. 制作チェックリスト
- [ ] 元データ（TikTokウォーターマークなし）からアップしているか
- [ ] アプリ内楽曲を使用しているか
- [ ] カルーセルの1枚目が止まる構図になっているか
- [ ] ビジュアルトーンが世界観（モノクロ・ノイズ感）に合っているか

## 8. 投稿チェックリスト
- [ ] キャプションにフック1行が入っているか
- [ ] ハッシュタグ10〜15個を設定したか
- [ ] 「プロフリンクからYouTube本編へ」の誘導が入っているか
- [ ] フィクション免責文を入れたか

## 9. 改善時に見るポイント
- 保存数が低い → カルーセルの情報密度を上げる。「保存しておきたい資料感」を強化
- プロフィール訪問が少ない → 冒頭の世界観設計を見直す
