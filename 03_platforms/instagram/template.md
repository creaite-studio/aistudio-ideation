## カルーセルテンプレ

### 1枚目：サムネイル（表紙）
```
[記録番号 / KF001]
[怪異名]
─────────────────
[強い違和感を与える一文]
※フィクションです
```

### 2枚目：概要（発生記録）
```
■ 発生場所：[地名 or 「非公開」]
■ 発生時期：[時期 or 「不明」]
■ 概要：[2〜3行。何が起きたかを淡々と]
```

### 3枚目：異常現象（観測記録）
```
■ 通常と異なる点：
・[異常1]
・[異常2]
・[異常3]

■ 繰り返し発生する条件：
[条件 or 「不明」]
```

### 4枚目：証言（関係者記録）
```
■ 証言No.1（匿名）
「[証言内容]」

■ 証言No.2（匿名）
「[証言内容]」

※証言者の個人情報は保護されています
```

### 5枚目：証拠（資料）
```
■ 証拠物件：
[証拠1の説明（手紙 / 写真 / 音声ログ / 映像など）]
[証拠2の説明]

■ 分析結果：
[専門家所見 or 「分析不能」]
```

### 6枚目：調査メモ
```
■ 現時点で分かっていること：
・[判明事実1]
・[判明事実2]

■ 現時点で分かっていないこと：
・[未解決点1]
・[未解決点2]
```

### 7枚目：他ファイルとの接続（任意）
```
■ 類似案件：
[KFxxx] [怪異名] との共通点：[共通点]

※関連ファイルの詳細はYouTube本編で
```

### 8枚目：未解決の問い（コメント誘導）
```
[怪異名]は現在も未解決です。

「なぜ[最も説明できない点]なのか」
説明できていません。

─────────────────
あなたはどう思いますか？
コメントで教えてください。
─────────────────
完全版 → プロフィールのリンクから🔗
```

## 避けること

- TikTok保存ファイルをそのままReelにアップロード（ウォーターマークで到達率が下がる）
- テキスト過多のカルーセル（1枚に詰め込みすぎない）
- 画質の低いAI生成画像（正方形・高解像度で出力する）
- ハッシュタグを30個以上入れる（スパム扱いされやすい）
