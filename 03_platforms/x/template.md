# X Template

## 投稿予告テンプレ（公開日の朝にスケジュール）

```
今夜[時刻]に投稿します。

[一文で内容を煽る]

本当にフィクションかどうか、あなたが判断してください。
#ホラー #考察
```

## 投稿告知テンプレ（公開直後）

```
【[シリーズ名] #○○ 更新】

[タイトル]

[一文で内容]

[動画URL]

#ホラー #考察 #未解決事件
```

## 考察煽りテンプレ（投稿2〜3時間後）

```
「[動画タイトル]」

[コメント欄で多く指摘された箇所を引用]
「[コメント内容]」

この指摘、正解に近いかもしれません。

[動画URL]
```

## 世界観投稿テンプレ（断片・調査メモ）

```
[KF番号] 調査メモ

[日付] [時刻]
[淡々とした事実の記述]
[説明できない異常]

現在調査中。

#ホラー #未解決
```

## スレッドテンプレ（考察シリーズ）

```
1/ [怪異名]について、気になる点が3つある。

2/ 一つ目は[異常点1]

3/ 二つ目は[異常点2]

4/ 三つ目は[異常点3]

5/ このうち1つだけが偶然ではない可能性がある。どれだと思いますか？
```

## 記録断片テンプレ（世界観投稿・単発）

```
[KF番号] ——

[日付] [時刻]
[淡々とした事実1行]
[説明できない異常1行]

調査継続中。

#ホラー #未解決
```

---

## 避けること

- 感嘆符・絵文字の多用（世界観が壊れる）
- 感情的な語り口（「怖すぎる！」など）
- 動画URLのみの投稿（テキストを1行でも入れる）
- 毎回同じテンプレ文言（ローテーションで飽きを防ぐ）
