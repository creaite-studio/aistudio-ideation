# YouTube Template

## 概要欄テンプレ

```
【シリーズ名 #○○】タイトル

[100文字以内の本文説明]

▶ このシリーズの再生リスト: [URL]
▶ 前回の動画: [URL]

━━━━━━━━━━━━━━
📱 TikTok  : @[アカウント名]
📸 Instagram: @[アカウント名]
🐦 X       : @[アカウント名]
📧 Substack: [URL]
━━━━━━━━━━━━━━
※このコンテンツはフィクションです。実在の人物・事件・場所とは一切関係ありません。
```

---

## サムネイル文言パターン

```
疑問型  ：「この手紙、誰が送ったのか」
数字型  ：「○分○秒 誰も気づいていない」
衝撃型  ：「[記録番号] 未公開の記録」
考察煽り：「あなたには分かりますか」
逆張り型：「これはフィクションです」
```

---

## 本編構成テンプレ（10〜20分）

```
00:00 フック（最初の30秒で「なぜ見るべきか」を提示）
01:00 背景説明（怪異が起きた状況・記録の発見経緯）
04:00 証拠・証言（映像・手紙・ログの提示）
10:00 核心（最も説明できない異常）
14:00 調査結果（分かったこと・分からないこと）
17:00 未解決の問い（「なぜ〇〇なのか、現在も説明されていない」）
18:00 考察誘導 + CTA（コメント・登録・次回予告）
```

### セクション詳細

**00:00〜00:30 フック**
```
[最も衝撃的な1カット or 一文から始める]
「これから話すことは、[説明しきれない出来事]です」
「最後まで見た人だけが、[違和感の核心]に気づきます」
```

**00:30〜03:00 背景説明**
```
[怪異ファイル番号]
[怪異名]

[発生経緯を淡々と語る]
「最初にこの[記録/映像/手紙]が確認されたのは、[時期・場所]です」
「当初は[無害な解釈]とされていました」
```

**03:00〜08:00 証拠・証言の提示**
```
「しかし、[解析/調査]を重ねると、[異常な点]が確認されました」
[証拠1の提示と説明]
[証言の引用（匿名）]
[証拠2の提示と説明]
```

**08:00〜12:00 核心**
```
「問題は、[最も説明できない点]です」
「[説明を試みたが説明できなかった試みの描写]」
「現在の科学・調査では説明がつきません」
```

**12:00〜15:00 調査結果**
```
■ 分かったこと：
・[判明事実1]
・[判明事実2]

■ 分かっていないこと：
・[未解決点1]
・[未解決点2]
```

**15:00〜17:00 未解決の問い**
```
「なぜ[最も説明できない点]なのか」
「この問いに対する答えは、現在も出ていません」
「[関連する他の怪異との接続があれば言及]」
```

**17:00〜18:00 考察誘導 + CTA**
```
「あなたはどう思いますか？コメントで教えてください」
「チャンネル登録で、次の怪異ファイルの通知を受け取れます」
「この怪異の完全版資料は、概要欄のSubstackリンクから」
```

## 避けること

- 導入が長すぎる（最初の30秒で引きを作れない動画は離脱率が高い）
- BGMが感情を誘導しすぎる（淡々とした語り口を壊す）
- 字幕なし（視聴完了率に影響する）
- サムネイルと内容が一致しない（低評価・離脱の原因）
- 「Part 1 / Part 2」表記（→ `記録No.001` 形式を使用）
