# YouTube Template

## 概要欄テンプレ

```
【シリーズ名 #○○】タイトル

[100文字以内の本文説明]

▶ このシリーズの再生リスト: [URL]
▶ 前回の動画: [URL]

━━━━━━━━━━━━━━
📱 TikTok  : @[アカウント名]
📸 Instagram: @[アカウント名]
🐦 X       : @[アカウント名]
📧 Substack: [URL]
━━━━━━━━━━━━━━
※このコンテンツはフィクションです。実在の人物・事件・場所とは一切関係ありません。
```

---

## サムネイル文言パターン

```
疑問型  ：「この手紙、誰が送ったのか」
数字型  ：「○分○秒 誰も気づいていない」
衝撃型  ：「[記録番号] 未公開の記録」
考察煽り：「あなたには分かりますか」
逆張り型：「これはフィクションです」
```

---

## 本編構成テンプレ（10〜20分）

```
00:00 フック（最初の30秒で「なぜ見るべきか」を提示）
01:00 背景説明（怪異が起きた状況・記録の発見経緯）
04:00 証拠・証言（映像・手紙・ログの提示）
10:00 核心（最も説明できない異常）
14:00 調査結果（分かったこと・分からないこと）
17:00 未解決の問い（「なぜ〇〇なのか、現在も説明されていない」）
18:00 考察誘導 + CTA（コメント・登録・次回予告）
```
