# YouTube Platform Guide

## 1. このSNSの役割
深掘りコンテンツの発信・収益化の中心。TikTok/Instagramから誘導した視聴者をファン化する場所。

## 2. 投稿する内容
- 本編（10〜20分）：怪異の全体像・考察・未解決の問い
- Shorts（60秒以内）：TikTokと同素材を流用

## 3. 投稿しない内容
- 説明過多の解説動画
- オチのある怖い話（余白を残す）
- 画質・音質が明らかに低いもの

## 4. 投稿方針
- サムネイルに力を入れる（クリック率に直結）
- タイトルに「実話」「記録」「#〇〇」を入れてシリーズ感を出す
- エンドカードで関連動画・チャンネル登録を促す
- 概要欄テンプレを必ず使う

## 5. 推奨投稿頻度
本編: 週1本（金・土 20:00）／Shorts: 週1〜2本

## 6. 成功指標
- 視聴完了率: 40%以上
- チャンネル登録者増加: 月+100人（初期）
- 高評価率: 5%以上

## 7. 制作チェックリスト
- [ ] サムネイルのテキストが7文字以内で読めるか
- [ ] タイトルにシリーズ名・番号が入っているか
- [ ] 最初の30秒に「なぜ見るべきか」が入っているか
- [ ] 概要欄テンプレを適用したか
- [ ] エンドカードに関連動画・登録ボタンを設置したか

## 8. 投稿チェックリスト
- [ ] サムネイルをアップロードしたか
- [ ] 概要欄にSNSリンクブロックを入れたか
- [ ] フィクション免責文を入れたか
- [ ] 再生リストに追加したか
- [ ] Xに投稿告知ポストをスケジュールしたか

## 9. 改善時に見るポイント
- 視聴完了率が低い → 離脱ポイントをアナリティクスで確認。中盤の「核心」が弱い可能性
- クリック率が低い → サムネイルを変える。タイトルのフックを強化する
