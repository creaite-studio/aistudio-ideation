## 2. 投稿自動化の実現性

### 結論：完全自動化は難しい、半自動化が現実的

動画は各プラットフォームで縦横比・尺・アルゴリズムが異なるため、**「動画は同じ素材→アップロードだけ各プラットフォームに個別」が最も効率的**。

### 推奨ツール

| ツール | 用途 | 費用 | 実現性 |
|--------|------|------|--------|
| **Buffer** | TikTok/Instagram/X/YouTubeのスケジュール投稿・キャプション管理 | 月$6〜 | ◎ まず入れる |
| **Repurpose.io** | YouTube→TikTok/Reels自動クロスポスト（ウォーターマーク除去対応） | 月$25〜 | ○ 本数が増えたら |
| **CapCut** | 動画編集→TikTok/Reels/Shorts用に書き出し | 無料〜 | ◎ 制作の起点に |
| **Notion + Buffer** | 投稿カレンダー管理 + スケジュール投稿 | 無料〜 | ◎ |

### 自動化できること / できないこと

**できること（自動化OK）:**
- 投稿日時のスケジューリング（Buffer）
- YouTube→TikTok/Reelsへのクロスポスト（Repurpose.io）
- X への予告ツイート自動投稿
- ハッシュタグの自動付与

**できないこと（手動が必要）:**
- 各プラットフォームのサムネイル最適化（YouTubeのみサムネイル重要）
- TikTokウォーターマーク付き動画のInstagram投稿（リーチが落ちる → 元データからアップが理想）
- コメントへの返信（初動30分以内の返信がアルゴリズムに効く）

### 推奨ワークフロー（1本の動画を4プラットフォームに展開）

```
① CapCutで縦型動画を編集（9:16）
    ↓
② TikTokに直接アップロード（ウォーターマークなし版を保存）
    ↓
③ 保存した動画をInstagram Reelsにアップ
    ↓
④ YouTube Shortsにアップ（同じファイル）
    ↓
⑤ Xに「投稿しました」予告ツイート（Buffer でスケジュール済み）
    ↓
⑥ YouTube長尺の場合のみ: 別途サムネイル作成・アップ
```

**時短ポイント:** ②③④は同じファイルで10分以内に完了。キャプションはプラットフォームごとにテンプレを持っておくと1〜2分で完成。

## 4. プラットフォーム別テンプレ

### YouTube 概要欄テンプレ
```
【シリーズ名 #○○】タイトル

[100文字以内の本文説明。「この動画では〇〇を公開します」]

▶ このシリーズの再生リスト: [URL]
▶ 前回の動画: [URL]

━━━━━━━━━━━━━━
📱 TikTok  : @[アカウント名]
📸 Instagram: @[アカウント名]
🐦 X       : @[アカウント名]
━━━━━━━━━━━━━━
※このコンテンツはフィクションです。実在の人物・事件・場所とは一切関係ありません。
```

### YouTube サムネイル文言パターン
```
疑問型  :「この手紙、誰が送ったのか」
数字型  :「○分○秒 誰も気づいていない」
衝撃型  :「[事件名] 未公開の記録」
考察煽り:「あなたには分かりますか」
```

### TikTok / Instagram Reel キャプションテンプレ
```
[フック1行：疑問形 or 衝撃的な一文。3秒で止まらせる]

[本文2〜3行：状況説明。「〇〇が〇〇した」という事実だけ書く]

続きはYouTubeで→プロフィールのリンクから🔗

[ハッシュタグ]
※フィクションです
```

**バリエーション（フックのパターン）:**
```
疑問型  :「この映像、本当にAIが生成したものですか？」
数字型  :「3人の関係者に届いた手紙。全員が同じ言葉を書いていた。」
共感型  :「ホラーを作ろうとしただけなのに、なぜこうなった」
逆張り型:「これはフィクションです。でも説明できないことが1つあります。」
```

### X 投稿テンプレ（3パターン）

**① 投稿予告ツイート（投稿日の朝に自動スケジュール）**

## 5. 投稿カレンダー設計（週次）

| 曜日 | プラットフォーム | コンテンツ | 目的 |
|------|----------------|-----------|------|
| 月 | TikTok/Reel | 短尺（60秒以内）考察煽り | 認知拡大 |
| 水 | TikTok/Reel | 短尺（60秒以内）シリーズ予告 | フォロワー誘導 |
| 金 | YouTube | 本編（10〜15分） | 収益・信頼構築 |
| 金（夜） | X | 考察煽りツイート | エンゲージメント |
| 土 | TikTok/Reel | 短尺（考察の答え合わせ or 次回予告） | リテンション |

**週5投稿（TikTok/Reel×3 + YouTube×1 + X×複数）が基本ライン。**  
Bufferでスケジュールすれば実作業は週2〜3時間で回せる。
