## 収益導線

### 72 Micro-Seasons
```
Substack Notes / Twitter / Instagram（認知・発見）
    ↓
Beehiiv 無料登録
    ↓ 3〜5号で信頼構築
Beehiiv 有料購読 $9/月
    + Ko-fi 季節PDFガイド $5〜8（衝動買い・単品）
    + Gumroad Annual Guide $20（熱狂ファン・まとめ買い）
    ↓ ファン化
長期購読 + Gumroadアフィリ経由の受動販売
```

### Bungu
```
Google検索（Ghost SEO）
    ↓
記事内アフィリエイトリンク → Amazon購入 → コミッション
    ↓
Beehiiv メルマガ登録（記事更新通知）
    ↓
Ko-fi セットアップPDF $5〜8
    or Gumroad Hobonichi Complete Guide $15
    ↓
Gumroadアフィリ登録クリエイターが拡散 → 受動収益
```

### Japan Travel Guide
```
TikTok（Indonesia向け動画）
    ↓
KaryaKarsa 週次シリアル購読 Rp 15,000〜30,000/月（$1〜2）
    + 単話購入（バックナンバー）
```
