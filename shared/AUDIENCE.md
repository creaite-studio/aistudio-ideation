# AUDIENCE.md — 72 Micro-Seasons

## Primary Audience（英語圏）

**Who**
- 日本の季節・自然・スローライフ・マインドフルネスに関心がある英語話者
- 忙しいが自分のリズムを整えたい人（20〜40代、都市在住）
- 占いより知的で、民俗・自然観察寄りのものが好きな人
- Fumio Sasaki・Marie Kondo・Wabi-Sabiを知っている層

**Pain**
- SNS情報がうるさすぎて疲れている
- 自分の生活リズムが乱れている・季節感を感じられない
- スピリチュアルに興味はあるが怪しすぎるものは苦手
- 「整う」コンテンツを求めているが、表面的なものが多い

**Desire**
- 季節に合わせた行動指針がほしい
- 美しいビジュアルで保存・共有したい
- 読むだけで整う。生活に落とし込める
- 自分だけのリズムや習慣を作りたい

**Where**
- Twitter/X（知識層・スレッドで深読み）
- Instagram（世界観・保存したいビジュアル）
- Substack（発見・他クリエイターからの流入）
- Beehiiv（深読み・有料購読）
