# SNS Research — 市場調査・競合分析・ペルソナ設計

WebSearch を使ってSNSの実データを調査し、構造化された分析結果を生成する。

## フェーズ構成

```
Phase 0: 調査設計
  ↓
Phase 1: 市場調査（投稿量・トレンド・需要）
  ↓
Phase 2: 競合分析（トップアカウント・バズパターン）
  ↓
Phase 3: ペルソナ設計（デモグラフィック・感情・行動）
  ↓
Phase 4: 勝ちパターン抽出・保存
```

---

## Phase 0: 調査設計

まず対象ジャンルを決め、`ideation/genres/[genre]/brainstorm/` の最新ファイルを確認し、**SNS展開ブリーフ** があれば読み込む。
ブリーフがある場合はその内容を前提として使い、不足情報だけユーザーに確認する。

**確認する情報:**

1. **プラットフォーム** — X / Instagram / TikTok / YouTube / note / その他
2. **ジャンル・テーマ** — 何について発信するか
3. **目的** — フォロワー獲得 / 集客 / 商品販売 / ブランディング
4. **差別化の軸** — ブリーフにあれば流用、なければ仮説を立てる
5. **競合の有無** — 参考にしたいアカウントがあれば聞く

ブリーフを読み込んだ場合は以下を表示してから調査開始:
```
📋 ブレストのブリーフを読み込みました
- コンセプト: [ブリーフの内容]
- ターゲット: [ブリーフの内容]
- プラットフォーム: [ブリーフの内容]
このブリーフをベースに調査します。修正があればお知らせください。
```

確認後: "調査を開始します。Phase 1〜3 を順に実行します。"

## Phase 1: 市場調査

WebSearch で以下を調査する:

**調査項目:**
- 該当ジャンルの投稿数・ハッシュタグ規模
- 検索ボリュームの高いキーワード
- 直近でバズったコンテンツのテーマ・形式
- プラットフォームのアルゴリズム傾向（2025〜2026）

**出力フォーマット（固定）:**

```
## 市場概況

| 項目 | 内容 |
|-----|-----|
| 市場規模感 | [投稿数・アクティブ度の概観] |
| 成長トレンド | [伸びているテーマ・形式] |
| 競合密度 | 高 / 中 / 低 |
| 参入余地 | [ニッチな切り口の有無] |

## バズテーマ TOP5
1. [テーマ] — [理由・特徴]
2. ...
```

---

## Phase 2: 競合分析

トップアカウント3〜5件を WebSearch で調査する。

**調査項目:**
- フォロワー数・エンゲージメント率
- 投稿形式（テキスト / 画像 / 動画 / ショート）
- 投稿頻度・時間帯
- バズ投稿の共通パターン（フック・構成・CTA）
- 収益化手段（アフィリエイト / 自社商品 / メンバーシップ等）

**出力フォーマット（固定）:**

```
## 競合分析

### [アカウント名]
- フォロワー: XX万
- 投稿形式: [形式]
- 強み: [1行]
- バズパターン: [フック→展開の型]

...（3〜5アカウント）

## 勝ちパターン（全競合共通）
1. [パターン1]
2. [パターン2]
3. [パターン3]

## 負けパターン（避けるべき）
1. [パターン1]
2. [パターン2]
3. [パターン3]
```

---

## Phase 3: ペルソナ設計

Phase 1〜2 の調査結果から、最重要ターゲットペルソナを1〜2体設計する。

**出力フォーマット（固定）:**

```
## ペルソナ: [名前（仮）]

| 項目 | 内容 |
|-----|-----|
| 年齢・性別 | [例: 28歳女性] |
| 職業・状況 | [例: 副業中のOL] |
| プラットフォーム利用 | [例: 通勤中にInstagramを1日30分] |
| 抱えている課題 | [具体的な悩み] |
| 感情的欲求 | [例: 「認められたい」「変わりたい」] |
| 行動トリガー | [どんな投稿に反応するか] |
| 離脱トリガー | [どんな投稿でフォロー解除するか] |

### このペルソナへの刺さる投稿
- [例文1]
- [例文2]
```

---

## Phase 4: 勝ちパターン抽出・保存

全フェーズの調査結果を統合して以下を出力する:

```
## 勝ちパターンサマリー

### 狙うべきニッチ TOP3
1. [ニッチ1] — [理由と参入戦略]
2. [ニッチ2] — ...
3. [ニッチ3] — ...

### 推奨ポジショニング
[競合との差別化軸を1〜2文で]

### 次のアクション
- [ ] sns-strategy でコンテンツ戦略・収益化計画を立案する
- [ ] ideation/genres/[genre]/personas/ にペルソナファイルを保存する
```

**ファイル保存:**
- 調査レポート全体 → `ideation/genres/[genre]/research/sns/YYYY-MM-DD-[プラットフォーム]-[ジャンル].md`
- ペルソナ定義 → `ideation/genres/[genre]/personas/[ペルソナ名].md`

保存後: "調査完了です。/sns-strategy でこの結果をもとに戦略を立案できます。"

---

## 制約・品質ルール

- 各フェーズの出力フォーマットは**必ず守る**（箇条書き・表形式を崩さない）
- 推測で書かない。WebSearch で根拠を取る
- 数値は具体的に（「多い」ではなく「フォロワー10万以上が5アカウント確認」）
- 調査結果には必ず情報源（URL or アカウント名）を記載
