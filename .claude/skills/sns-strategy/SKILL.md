# SNS Strategy — フォロワー獲得戦略・収益化ロードマップ

対象ジャンルを決め、調査結果（ideation/genres/[genre]/research/sns/ と ideation/genres/[genre]/personas/）を読み込み、実行可能な戦略を設計する。

## フェーズ構成

```
Phase 0: 前提確認
  ↓
Phase 1: ポジショニング設計
  ↓
Phase 2: コンテンツ戦略
  ↓
Phase 3: フォロワー獲得プラン
  ↓
Phase 4: 収益化ロードマップ
  ↓
Phase 5: 実行計画・保存
```

---

## Phase 0: 前提確認

1. sns-research の調査結果ファイルが `ideation/genres/[genre]/research/sns/` にあれば読み込む
2. ペルソナ定義が `ideation/genres/[genre]/personas/` にあれば読み込む
3. 不足情報をユーザーに確認:
   - プラットフォーム・ジャンル（未調査の場合）
   - 現在のフォロワー数・投稿実績
   - 目標フォロワー数・達成期間
   - 使えるリソース（投稿頻度、制作時間/週）
   - 最終的なマネタイズ手段のイメージ

```
### 投稿ネタ（各ジャンル3本）

#### [ジャンル1]
1. [ネタ1] — [想定反応・理由]
2. [ネタ2] — ...
3. [ネタ3] — ...

（ジャンル2, 3も同様）

### バズテンプレ

**フック（最初の1行）パターン:**
- 数字型: [例: 「月3万稼ぐために捨てた3つのこと」]
- 共感型: [例: 「副業始めて1年、正直しんどかった話」]

**投稿構成テンプレ:**

```

## 制約・品質ルール

- 各フェーズの出力フォーマットは**必ず守る**
- 「頑張る」「継続する」のような精神論は書かない。具体的アクションのみ
- 数値目標は必ず設定する（「増やす」ではなく「週+50人」）
- プラットフォームのアルゴリズム特性に合わせた戦略にする
- sns-research の結果がある場合は必ず反映する
