# ホラーSF創作アカウント 運用リポジトリ

## アカウントの目的

誰も語らなかった闇を記録する。未解決事件・AI恐怖映像・制作者自身のドキュメントを軸に、「本当にフィクションかどうか」という余白を持ったコンテンツを発信する。

## ディレクトリ構成

```
01_account/    → アカウントの正体を決める
02_strategy/   → どう伸ばすかを決める
03_platforms/  → SNSごとの型を決める（03_platforms = 型紙）
04_kaii-files/ → 怪異本体と制作物を管理する（04_kaii-files = 事件箱）
05_analytics/  → 反応を見て改善する（05_analytics = 検死報告書）
99_archive/    → 古い案・没案を保管する
```

## 基本ワークフロー

```
01_account（世界観・プロフィールを決める）
  ↓
02_strategy（投稿頻度・収益化計画を決める）
  ↓
03_platforms（SNSごとの役割と投稿テンプレートを作る）
  ↓
04_kaii-files（怪異を作る → SNS別に制作する → 投稿する）
  ↓
05_analytics（数値を見る → 改善点を記録 → 各ファイルへ反映）
```

## 命名ルール

| 種類 | 命名規則 |
|-----|---------|
| 怪異ファイル | `KF001_怪異名/` |
| 実験ファイル | `EXP001_テーマ.md` |
| 日付ファイル | `YYYY-MM-DD-テーマ.md` |

## 更新ルール

- SNSごとの型は `03_platforms` のみで管理する
- 怪異の制作物は `04_kaii-files/KFxxx/` 内に完結させる
- 分析結果は `05_analytics` に記録し、改善は元ファイルへ反映する
- 没案・旧版は削除せず `99_archive` へ移動する
