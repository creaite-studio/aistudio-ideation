## テーマ別・プラットフォーム優先度

### 72 Micro-Seasons

```
◎ Beehiiv   → 収益の中心（購読課金・PDFデジタル販売）
◎ Substack  → 発見の入り口（Notes経由で自然流入）
○ Twitter/X → 拡散・共感獲得
○ Instagram → 世界観をビジュアルで届ける
△ Medium    → 記事を流用してPV収益（工数最小）
△ TikTok    → 動画化できる記事が出たら追加
△ KaryaKarsa→ Phase 3以降・インドネシア語展開
✗ Ghost     → 72候はSEO主軸ではないので不要
```

### Bungu

```
◎ Ghost     → 収益の中心（SEO×アフィリエイト）
◎ Instagram → 購買欲を刺激するビジュアル
○ Medium    → Ghost記事を流用してPV収益
○ Twitter/X → 文具コミュニティとの接点
○ Beehiiv   → ファンとの関係・Hobonichi新情報
△ Ko-fi     → セットアップPDF販売
✗ Substack  → API制限で自動化できず不採用
✗ KaryaKarsa→ 文具ニーズはインドネシアで薄い
```

## アルゴリズム攻略ポイント（全PF）

### Beehiiv
- **件名が開封率を決める**: 数字・感情・好奇心のどれか1つを入れる
  - 良い例: `"The Japanese season that lasts just 5 days"`
  - 良い例: `"Frogs began singing in Japan this morning"`
- 毎回同じ曜日・時刻に送る（習慣化）
- 毎号1箇所に自然な有料CTAを入れる

### Substack
- **Notesが発見の鍵**: 記事の抜粋・詩的な一文をNotesに毎日投稿
- **リスタック（Restack）が最も強い成長シグナル**: 他のクリエイターをRestackする→返してもらえる
- **ライブ配信**は全購読者にメール通知→即時エンゲージに使える
- SubstackはBeehiivの**発見装置**として使い、収益はBeehiivに集約する設計

### Ghost
- タイトルに検索キーワードを入れる（例: `"Best Hobonichi Cover 2027 — Full Comparison"`）
- H2見出しにも副キーワードを使う
- 記事間の内部リンクを意識的に設計する（トピッククラスター）
- 1記事 = 1検索意図に絞る

### Medium
- **タグを5つ正確に選ぶ**（Japan / Minimalism / Stationery / Slow Living / Mindfulness）
- Mediumキュレーターに選ばれると一気に流入が増える（質の高い書き出しが鍵）
- Ghost/Beehiivと**重複コンテンツにならないよう**canonicalタグを設定するか、要約版を載せる

### Twitter/X
- **外部リンクは本文に入れない** → リプライに貼る（ペナルティ回避）
- 本文の末尾に「リンクはリプライに 👇」と書く
- 返信を引き出す問いかけで締める（返信 = いいねの150倍の重み）
- ハッシュタグは最大1〜2個
- スレッド形式（単体ツイートの3倍エンゲージメント）

### Instagram
- **1枚目でスクロールを止める**: テキストオーバーレイ必須
- カルーセルの最終枚に「保存してね」を入れる（保存 = 強いシグナル）
- DMで送りたくなるコンテンツ = 最強の拡散シグナル
- 直近9〜12投稿でジャンルが決まる → ニッチを絶対ぶらさない
- Reels = 新規発見 / カルーセル = 既存フォロワー深耕

### TikTok
- **最初の8秒で視聴継続率を上げる**（フック必須）
- 投稿の80%以上を同じニッチに保つ
- 完走率 > いいね数（短く作って完走させる）
- 日本の自然・季節・手仕事コンテンツはTikTokで強いジャンル

### Ko-fi
- 発見性はゼロなのでBeehiiv/Ghostからの誘導が前提
- 価格帯は$5〜8（衝動買いライン）
- バンドル（季節PDF4冊セット $25など）で客単価を上げる

### KaryaKarsa
- インドネシア語コンテンツが前提（翻訳はClaude APIで自動化）
- 週次シリアル形式が最もウケる（続きを読ませる構成）
- 72候の「今週の自然」形式はシリアルと相性が良い

### 72 Micro-Seasons

#### Beehiiv（収益の中心）
```
頻度: 5日に1回（候に合わせて自動）
構成:
  件名例: "Frogs began to sing in Japan today"
          "The 5-day season most people miss"
  本文:
    ① 今日の候の詩的な描写（日本にいる自分の一人称）
    ② 候の語源・歴史（200字程度）
    ③ この候の過ごし方・旬の食材・行事
    ④ 読者への問いかけ（"What season are you in right now?"）
    ⑤ 有料CTAは月1〜2回だけ（しつこくしない）

無料/有料の分け方:
  無料: 候の基本解説・詩的な描写
  有料: 深掘り（食材レシピ・哲学・行事の由来・PDFガイド付き）
```

#### Substack（発見の入り口）
```
役割: Beehiivに誘導するための「発見装置」
戦略:
  - Beehiivの記事の要約版・抜粋をNotesに毎日投稿
  - 「全文はBeehiivで」という導線を作る
  - 他のSlowLiving系Substackをリスタックして関係構築
  ※ 収益はBeehiivに集約（Substackの10%手数料を避ける）
```

#### Twitter/X
```
頻度: 週3〜4回
投稿タイプ:
  ① 候スレッド（メイン）:
     "🧵 Today in Japan, a new micro-season begins.
      It's called 蛙始鳴 — 'frogs begin to sing.'
      Here's what that means, and why it matters."
     → 8〜10ツイートで候を解説、最後のツイートにBeehiivリンク
  ② 写真1枚 + 一行詩（日本の風景）
  ③ 「この概念は英語に訳せない」系フック投稿
```

#### Instagram
```
頻度: 週2〜3回
投稿タイプ:
  ① カルーセル（週2回）:
     1枚目: 候の名前を大きく（日英）＋季節の写真
     2〜4枚: 意味・語源・自然の変化
     5〜6枚: 過ごし方・食材・行事
     最終枚: "Save this for the season 🍃" + 次の候予告
  ② Reels（週1回）:
     日本の自然映像 + テキストオーバーレイ
     15〜30秒・完走率最優先
```

#### Ko-fi（デジタル販売）
```
商品ラインナップ:
  ① 季節PDFガイド（春/夏/秋/冬）各$6
     → 各季節18候を1冊にまとめたデジタルガイド
  ② 72候デスクトップカレンダー（デジタル）$8
  ③ 候ジャーナルテンプレート $5
  ④ 4冊セット $20（単品$24→まとめ買い促進）
```

### Bungu / Japanese Stationery

#### Ghost（収益の中心）
```
頻度: 週1〜2本
記事タイプ:
  ① SEOレビュー記事（アフィリ主軸）:
     "Hobonichi Techo 2027: Full Review After 3 Months"
     "Best Japanese Fountain Pens Under $50 (2026)"
     → タイトルに年号・価格帯・比較語を入れる
  ② エバーグリーンガイド:
     "How to Start Using Hobonichi Techo"
     "Why Japanese Stationery Is Engineered Differently"
     → 何年経っても検索される永続コンテンツ
  ③ 文化記事（権威性）:
     "Visiting Tokyo's Best Stationery Stores"
     → 日本在住の一次情報で差別化

アフィリエイトの入れ方:
  本文中に自然な形で挿入
  プレースホルダー: <!-- AFFILIATE: product-key -->
  記事末尾に「この記事で紹介した商品まとめ」セクション必須
  商品リスト参照: content/bungu/_affiliate-products.md
```

#### Medium（Ghost記事を流用して収益化）
```
戦略:
  Ghostの記事を要約・リライトしてMediumにも投稿
  → 追加工数ほぼゼロで$24/1,000views の収益追加
  ※ canonicalタグをGhostのURLに向けてSEO影響を回避
  タグ: Japan / Stationery / Productivity / Minimalism / Design
```

#### Beehiiv（コミュニティ維持）
```
頻度: 週1回
内容:
  ① Hobonichi新作・限定コラボ速報
  ② 今週見つけた日本文具の話（短め）
  ③ Ghost最新記事の紹介+一言コメント
  ④ 読者の文具デスク写真紹介（コミュニティ感）
無料のみ（Bunguはアフィリで稼ぐため課金設定は不要）
```

#### Instagram（購買欲を刺激）
```
頻度: 週3〜4回
投稿タイプ:
  ① デスクセットアップカルーセル（週2回）:
     「私の文具全部見せます」型
     各商品にタグ＋最終枚にアフィリCTA
  ② Hobonichiページ紹介（使い方カルーセル）
  ③ Reels（週1〜2回）:
     開封動画・書き比べ動画・文具店巡り
     購買欲を刺激する30〜60秒
```

#### Twitter/X
```
頻度: 週2〜3回
投稿タイプ:
  ① 「日本の文具が違う理由」スレッド:
     "Why does this $8 Japanese eraser feel so different?
      A thread on Japanese stationery engineering 🧵"
  ② 商品1点フィーチャー（写真+3行）
  ③ Hobonichi関連速報（発売日・新柄）
```

## Phase 1 フォーカス（最初の2ヶ月）

```
やること（4つだけ）:
  1. Beehiiv セットアップ → 72候ニュースレター開始
  2. Ghost セットアップ  → Bungu記事を週1本
  3. Substack Notes     → 毎日1投稿（Beehiivへの誘導）
  4. Twitter            → 週3回スレッド

やらないこと:
  - Instagram（フォロワーゼロから始めるには工数が重い）
  - TikTok（動画制作コストが高い）
  - KaryaKarsa（Phase 3以降）
  - Ko-fi（読者が集まってから）
```
